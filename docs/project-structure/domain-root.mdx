# Domain root

The domain root is the single entry point for the compiled model. It keeps the model inventory, bounded contexts, and a composition-only module file together under one predictable directory.

- Put one explicit `domain_model!` composition in `model.rs`.
- Keep each bounded context and its vocabulary in a dedicated directory.
- Reserve the root `mod.rs` for module declarations and scoped re-exports.

Path: `src/domain`

The `bike-rental` application composes three bounded contexts. `rental` owns the
fleet and tariffs, `finance` owns payments, and `workshop` owns repair jobs.
Tests under `src/domain/tests` mirror those context directories.

<ProjectStructureExample name="domain-root">

```rust
domain_model! {
    contexts: [Rental, Finance, Workshop],
    aggregates: [RentalFleetAggregate, RentalTariffAggregate, RentalPaymentAggregate, RepairJobAggregate],
    // The full inventory also declares entities, value objects, services, and errors.
}
```

</ProjectStructureExample>
