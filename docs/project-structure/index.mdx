# Project structure

Rostfrei uses predictable directories to connect each domain declaration with its owner and implementation. Choose the page that matches the concept or capability you are adding.

Run `cargo rostfrei check --workspace` to validate configured packages. The checker verifies file roles and implementation targets, then runs each package's compiled-model check. Business rules still require tests.

**New to the model?** Follow the [bike-rental walkthrough](../getting-started.mdx) first. For the declarations inside these files, see [Domain macros](../domain-macros/index.mdx).
