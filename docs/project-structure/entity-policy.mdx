# Entity policy

An entity policy evaluates facts from one entity without changing its state. The trait, outcome enum, and implementation live in the same capability directory.

- Declare the trait in `policy.rs`.
- Define exhaustive outcomes in `outcome.rs`.
- Implement the policy directly for the entity in `evaluate.rs`.
- Use lifecycle evaluation to check whether a transition is legal.

Path: `src/domain/bike_rental/rental_fleet/bicycle/assess_rental_eligibility`

<ProjectStructureExample name="entity-policy">

```rust
use rostfrei::{LifecycleState, domain_policy};

use super::RentalEligibilityOutcome;
use crate::domain::rental_fleet::{
    Bicycle, BicycleCondition, BicycleRentalTransition,
};

#[domain_policy(
    id = "assess-rental-eligibility",
    label = "Assess rental eligibility"
)]
pub(in crate::domain) trait RentalEligibilityPolicy {
    fn assess_rental_eligibility(&self) -> RentalEligibilityOutcome;
}

impl RentalEligibilityPolicy for Bicycle {
    fn assess_rental_eligibility(&self) -> RentalEligibilityOutcome {
        if self
            .status()
            .evaluate(&BicycleRentalTransition::Rent)
            .is_err()
        {
            return RentalEligibilityOutcome::UnavailableStatus;
        }

        if self.condition() == BicycleCondition::MaintenanceRequired {
            return RentalEligibilityOutcome::MaintenanceRequired;
        }

        RentalEligibilityOutcome::Eligible
    }
}
```
