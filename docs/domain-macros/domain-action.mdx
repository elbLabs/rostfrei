# `domain_action`

Adds an ID, label, and descriptor to an ordinary Rust trait. Method signatures remain application-defined. The structure checker verifies that `execute.rs` implements the trait for the owner selected by its directory.

**Placement:** [Aggregate action](../project-structure/aggregate-action.mdx), [entity action](../project-structure/entity-action.mdx), [value-object action](../project-structure/value-object-action.mdx), or a focused capability below a [Domain service](../project-structure/domain-service.mdx) — `action.rs`.

```rust
#[domain_action(id = "rent-bicycle", label = "Rent bicycle")]
pub trait RentBicycleAction {
    fn rent_bicycle(
        &mut self,
        input: BicycleId,
    ) -> Result<(), BicycleUnavailable>;
}
```
