# Domain macros

Domain macros describe types, behavior contracts, and model composition. Some also generate runtime adapters or JSON codecs. Each page shows the declaration and its expected location.

Your types and trait implementations carry the business rules. The macros describe their roles and relationships so the compiled model, runtime, and developer tools can work with the same contracts.

**New to Rostfrei?** Start with the [bike-rental walkthrough](../getting-started.mdx) to see these declarations in a working application. Use this reference when you are ready to read or write a specific contract, and [Project structure](../project-structure/index.mdx) to find its home.
