# `domain_*_test`

Connects a Rust test to an action, policy, invariant, or lifecycle descriptor. The test body stays unchanged. An ignored companion test emits metadata for discovery.

**Placement:** Under `src/domain/tests`, mirroring the subject's path. For example, the fleet invariant's tests live in `tests/bike_rental/rental_fleet/fleet_consistency.rs` beneath the domain root.

```rust
#[domain_invariant_test(
    <RentalFleetAggregate as FleetConsistency>::DESCRIPTOR
)]
fn exposes_owner_independent_invariant_metadata() {
    // inspect the authored invariant descriptor
}
```
