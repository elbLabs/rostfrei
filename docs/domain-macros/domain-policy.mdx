# `domain_policy`

Adds metadata to a trait for a reusable, pure interpretation of domain facts. A policy returns an outcome without changing state or recording events. Use [`PolicyOutcome`](policy-outcome.mdx) when the outcomes need a named, exhaustive vocabulary.

Implement the trait for an aggregate, entity, value object, or domain service. The structure checker validates placement and ownership; it does not prove that an implementation is pure.

**Placement:** [Aggregate policy](../project-structure/aggregate-policy.mdx), [Entity policy](../project-structure/entity-policy.mdx), [value-object policy](../project-structure/value-object-policy.mdx), or a focused capability below a [Domain service](../project-structure/domain-service.mdx) — `policy.rs`.

```rust
#[domain_policy(
    id = "assess-rental-eligibility",
    label = "Assess rental eligibility"
)]
pub trait RentalEligibilityPolicy {
    fn assess_rental_eligibility(&self) -> RentalEligibilityOutcome;
}
```
