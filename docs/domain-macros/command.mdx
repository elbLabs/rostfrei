# `Command`

Declares a bounded-context command and generates its JSON payload codec. Set `context` to the owning bounded context and include every required aggregate ID in the payload. The schema version defaults to 1.

The registered handler loads the participating aggregates and declares the command's rejection type.

**Placement:** `command.rs` beside its handler, in an [aggregate action](../project-structure/aggregate-action.mdx) or [domain service](../project-structure/domain-service.mdx) module.

```rust
#[derive(Command, Clone, Debug)]
#[domain(
    id = "collect-reserved-bicycle",
    label = "Collect reserved bicycle",
    context = BikeRental
)]
pub struct CollectReservedBicycle {
    pub fleet_id: FleetId,
    pub reservation_id: ReservationId,
    pub bicycle_id: BicycleId,
    pub payment_id: PaymentId,
    pub payment_method: String,
}
```
