# `Aggregate`

Adds an ID and label to an aggregate marker. Implement `AggregateDefinition` to select its bounded context, root entity, and event set. The derive connects those types to the event-sourcing runtime.

**Placement:** [Aggregate](../project-structure/aggregate.mdx) — `aggregate.rs`.

```rust
#[derive(Aggregate)]
#[domain(id = "rental-fleet", label = "Rental fleet")]
pub struct RentalFleetAggregate;

impl AggregateDefinition for RentalFleetAggregate {
    type Context = BikeRental;
    type Root = RentalFleet;
    type Event = RentalFleetEvent;
}
```

Set `const ANCHOR: bool = true` in `AggregateDefinition` to advertise this aggregate
as an inspection anchor (the default is `false`). The domain model and Tracer
catalog expose the `anchor` flag. It selects a viewpoint for
[retained correlation inspection](../continuous-observation.md#retained-correlation-inspection);
it does not change aggregate ownership or event storage.
