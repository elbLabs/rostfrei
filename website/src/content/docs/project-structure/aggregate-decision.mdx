# Aggregate decision

An aggregate decision keeps a pure business policy beside its closed outcome vocabulary. The contract, outcomes, and evaluation live separately so policy remains reviewable without state mutation or persistence code.

- Declare the trait in `decision.rs`.
- Define exhaustive outcomes in `outcome.rs`.
- Implement the decision for the aggregate type in `evaluate.rs`.

Illustrative path: `src/domain/bike_rental/rental_fleet/plan_fleet_capacity`

The bike-rental example's rental-eligibility policy belongs to a Bicycle and is documented as an [Entity decision](/docs/project-structure/entity-decision). This aggregate-level capability is an illustrative shape.

<ProjectStructureExample name="aggregate-decision">

```rust
use rostfrei::domain_decision;

use super::FleetCapacityOutcome;

#[domain_decision(
    id = "plan-fleet-capacity",
    label = "Plan fleet capacity"
)]
pub(in crate::domain) trait FleetCapacityDecision {
    fn plan_fleet_capacity(&self) -> FleetCapacityOutcome;
}
```
