# Entity action

An entity action is a small behavior capability nested directly below the entity it changes. Structure binds the action implementation to the entity declared in the neighboring `entity.rs`.

- Put the trait in `action.rs`.
- Implement the trait directly for the entity in `execute.rs`.
- Keep unrelated aggregate orchestration outside this directory.

Illustrative path: `src/domain/bike_rental/rental_fleet/bicycle/change_condition`

This capability is intentionally illustrative. The bike-rental example applies rental-status changes from recorded events through its lifecycle instead of exposing them as Entity actions.

<ProjectStructureExample name="entity-action">

```rust
#[domain_action(id = "change-condition", label = "Change condition")]
pub trait ChangeConditionAction {
    fn change_condition(&mut self, condition: BicycleCondition);
}

impl ChangeConditionAction for Bicycle {
    fn change_condition(&mut self, condition: BicycleCondition) {
        self.condition = condition;
    }
}
```

</ProjectStructureExample>
