# Entity decision

An entity decision keeps pure business interpretation next to the Entity whose facts it evaluates. Its contract, exhaustive outcomes, and evaluator remain separate from state mutation and persistence.

- Declare the trait in `decision.rs`.
- Define exhaustive outcomes in `outcome.rs`.
- Implement the decision directly for the Entity in `evaluate.rs`.
- Compose lifecycle evaluation with other policy instead of duplicating transition topology.

Path: `src/domain/bike_rental/rental_fleet/bicycle/assess_rental_eligibility`

<ProjectStructureExample name="entity-decision">

```rust
use rostfrei::{LifecycleState, domain_decision};

use super::RentalEligibilityOutcome;
use crate::domain::rental_fleet::{
    Bicycle, BicycleCondition, BicycleRentalTransition,
};

#[domain_decision(
    id = "assess-rental-eligibility",
    label = "Assess rental eligibility"
)]
pub(in crate::domain) trait RentalEligibilityDecision {
    fn assess_rental_eligibility(&self) -> RentalEligibilityOutcome;
}

impl RentalEligibilityDecision for Bicycle {
    fn assess_rental_eligibility(&self) -> RentalEligibilityOutcome {
        if self
            .status()
            .evaluate(&BicycleRentalTransition::Rent)
            .is_err()
        {
            return RentalEligibilityOutcome::UnavailableStatus;
        }

        if self.condition() == BicycleCondition::MaintenanceRequired {
            return RentalEligibilityOutcome::MaintenanceRequired;
        }

        RentalEligibilityOutcome::Eligible
    }
}
```
