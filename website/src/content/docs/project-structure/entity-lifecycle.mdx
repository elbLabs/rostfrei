# Entity lifecycle

An entity lifecycle keeps the entity's authoritative stored state and legal state changes together. Evaluation is pure: it checks topology while actions, decisions, and events retain business policy and side effects.

- Put the state enum in `lifecycle.rs` and the transition enum in `transition.rs`.
- Give every state a stable ID and label.
- Declare exactly one initial state and one source/target edge per transition.
- Keep state-changing actions in separate capability directories.

Path: `src/domain/bike_rental/rental_fleet/bicycle/rental_status/lifecycle.rs`

<ProjectStructureExample name="entity-lifecycle">

```rust
use rostfrei::EntityLifecycle;

#[derive(EntityLifecycle, Clone, Copy, Eq, PartialEq)]
#[domain(id = "rental-status", label = "Bicycle rental status")]
#[lifecycle(initial = Available)]
pub enum BicycleStatus {
    #[state(id = "available", label = "Available")]
    Available,
    #[state(id = "rented", label = "Rented")]
    Rented,
}
```

</ProjectStructureExample>

Path: `src/domain/bike_rental/rental_fleet/bicycle/rental_status/transition.rs`

```rust
use rostfrei::StateTransition;

#[derive(StateTransition)]
#[transition(state = BicycleStatus)]
pub enum BicycleRentalTransition {
    #[edge(id = "rent", label = "Rent", from = Available, to = Rented)]
    Rent,
    #[edge(id = "return", label = "Return", from = Rented, to = Available)]
    Return,
}
```
