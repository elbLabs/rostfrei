# Behaviorful value object

A value object with behavior keeps its declaration in `value.rs` and each action, policy, or invariant in a child directory.

- Anchor the value in `value.rs`.
- Give each capability a named child directory.
- Keep each child’s contract separate from its implementation.

Path: `src/domain/bike_rental/rental_fleet/bicycle/registration_number`

<ProjectStructureExample name="behaviorful-value-object">

```rust
#[derive(ValueObject, Clone, Debug, Eq, PartialEq)]
#[domain(
    id = "registration-number",
    label = "Registration number"
)]
pub struct RegistrationNumber(String);
```

</ProjectStructureExample>
