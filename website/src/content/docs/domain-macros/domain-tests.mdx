# `domain_*_test`

Attach evidence to its subject. Action, query-independent decision, invariant, and lifecycle tests remain normal Rust tests with discoverable subject metadata. The attribute connects a test to its typed descriptor.

- Authored body stays unchanged
- Typed descriptor expression
- Ignored discovery companion

**Placement:** Beside the owning [action](/docs/project-structure/aggregate-action), [decision](/docs/project-structure/aggregate-decision), [invariant](/docs/project-structure/aggregate-invariant), or [lifecycle](/docs/project-structure/entity-lifecycle) tests. Entity decisions use the same test shape inside their Entity directory.
