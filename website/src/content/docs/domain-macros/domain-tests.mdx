# `domain_*_test`

Attach evidence to its subject. Action, policy, invariant, and lifecycle tests remain normal Rust tests with discoverable subject metadata. The attribute connects a test to its typed descriptor.

- Authored body stays unchanged
- Typed descriptor expression
- Ignored discovery companion

**Placement:** Beside the owning [action](/docs/project-structure/aggregate-action), [policy](/docs/project-structure/aggregate-policy), [invariant](/docs/project-structure/aggregate-invariant), or [lifecycle](/docs/project-structure/entity-lifecycle) tests. Entity policies and lifecycles use the same test shape inside their owning directory.
