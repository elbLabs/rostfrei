# `StateTransition`

Declares the legal transitions of one lifecycle. Each fieldless variant names one transition and lists one or more source/target state pairs.

**Placement:** [Lifecycle](/docs/project-structure/entity-lifecycle) — `transition.rs` beside `lifecycle.rs`.

<MacroExample name="StateTransition" />

The generated implementation returns `StateChange` only when the current state matches one of the transition's edge sources. Duplicate source states within one variant are rejected, so a `(transition, current state)` pair has at most one target. Use policies and invariants for rules that require additional domain facts.
