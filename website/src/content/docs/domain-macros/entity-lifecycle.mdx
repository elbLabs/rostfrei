# `EntityLifecycle`

Name lifecycle states without inventing behavior. Lifecycle metadata is an ordered vocabulary. Initial state, transitions, and ownership remain intentionally unspecified. Use the enum only to declare recognized states.

- Fieldless enum
- Ordered state metadata
- No transition engine yet

**Placement:** [Entity lifecycle](/docs/project-structure/entity-lifecycle) — `lifecycle.rs`.
