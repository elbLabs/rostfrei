# `EntityLifecycle`

Make an aggregate root's or nested Entity's stored state its lifecycle state. The derive adds stable state metadata, an explicit initial state, and the `LifecycleState` implementation used to evaluate typed transitions.

- Fieldless enum
- One explicit initial state
- Pure transition evaluation through `LifecycleState`

**Placement:** [Lifecycle](/docs/project-structure/entity-lifecycle) — `lifecycle.rs` in a lifecycle directory directly beneath the owning aggregate or nested Entity.

<MacroExample name="EntityLifecycle" />

Pair it with [`StateTransition`](/docs/domain-macros/state-transition). Business guards and side effects remain in ordinary actions, policies, and event handling.
