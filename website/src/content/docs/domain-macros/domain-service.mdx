# `DomainService`

Put cross-entity behavior in context. The derive names the service; DomainServiceDefinition supplies the only required relationship. Service behavior remains explicit in the surrounding domain code.

- Non-generic unit struct
- Context relationship is explicit
- No implicit actions

**Placement:** [Domain service](/docs/project-structure/domain-service) — `service.rs`.
