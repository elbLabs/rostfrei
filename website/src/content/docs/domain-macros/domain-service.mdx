# `DomainService`

Give stateless cross-object domain behavior an explicit owner. The derive names the service marker; `DomainServiceDefinition` connects it to one bounded context. Focused Actions and Domain Policies remain ordinary traits in child capability directories.

- Non-generic unit struct
- Context relationship is explicit
- No implicit capabilities or infrastructure

**Placement:** [Domain service](/docs/project-structure/domain-service) — `service.rs`.
