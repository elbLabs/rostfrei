# `DomainIdentity`

Any Rust type can be an identity. The derive is deliberately only a semantic marker. The EntityDefinition accessor gives it meaning. Keep representation and supporting traits fully under application control.

- Struct or enum
- No scalar declaration
- UUIDs and custom types work

**Placement:** [Entity](/docs/project-structure/entity) — `identity.rs`.
