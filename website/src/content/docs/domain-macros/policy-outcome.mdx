# `PolicyOutcome`

Assigns a local ID and label to each variant of a non-empty outcome enum. Variants may carry ordinary Rust payloads. Rust's exhaustive matching lets callers handle every declared outcome.

**Placement:** [Aggregate policy](/docs/project-structure/aggregate-policy), [Entity policy](/docs/project-structure/entity-policy), or [value-object policy](/docs/project-structure/value-object-policy) — `outcome.rs`.
