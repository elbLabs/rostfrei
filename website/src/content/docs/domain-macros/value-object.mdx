# `ValueObject`

Tag only genuinely semantic values. A Value Object keeps a global semantic ID and label without claiming a field shape or transport schema. Define its representation as ordinary Rust.

- Struct or enum
- ID and label only
- Always declared in value.rs

**Placement:** [Simple value object](/docs/project-structure/simple-value-object) or [behaviorful value object](/docs/project-structure/behaviorful-value-object) — `value.rs`.
