# `ValueObject`

Assigns a semantic ID and label to a struct or enum representing a domain value. Its representation and behavior remain ordinary Rust; the derive does not generate a transport schema.

**Placement:** [Simple value object](/docs/project-structure/simple-value-object) or [behaviorful value object](/docs/project-structure/behaviorful-value-object) — `value.rs`.
