# `domain_action`

Adds an ID, label, and descriptor to an ordinary Rust trait. Method signatures remain application-defined. The structure checker verifies that `execute.rs` implements the trait for the owner selected by its directory.

**Placement:** [Aggregate action](/docs/project-structure/aggregate-action), [entity action](/docs/project-structure/entity-action), [value-object action](/docs/project-structure/value-object-action), or a focused capability below a [Domain service](/docs/project-structure/domain-service) — `action.rs`.
