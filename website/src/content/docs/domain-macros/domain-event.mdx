# `DomainEvent`

Declares a domain event's ID, label, fields, and schema version (1 by default). The payload describes a fact recorded in aggregate history. Derive serialization separately and include the type in the aggregate's [`AggregateEvents`](/docs/domain-macros/aggregate-events) enum.

**Placement:** [Aggregate action](/docs/project-structure/aggregate-action) — `event.rs`.

<MacroExample name="DomainEvent" />

Committed domain events can also update a [read model](/docs/read-models). Register
typed transformations and let the runtime load, checkpoint, and persist the query view.
